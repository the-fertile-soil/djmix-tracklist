# Example: Manoo at Djoon, July 12, 2025

A finished track list built with this tool. Open index.html in a browser.
Click a time to jump to that point in the mix.

[Watch the original mix on YouTube](https://www.youtube.com/watch?v=p01N7mNPwwU)

The page expects the audio file next to it, named manoo-djoon.mp3.
The recording is not included in this repository.

The main list holds the tracks heard more than once. The second list holds
tracks heard only once, which are usually quick vocal layers, accapellas or
samples. Entries marked "vocal" are vocal only or vocal heavy.
